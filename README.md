- 🃏 **Deck de Swipe Interativo (Estilo Tinder / Reigns)**:
  - Arraste o cartão de empréstimo para a direita para **Aprovar** ou para a esquerda para **Recusar** com física suave e carimbos neon animados.
  - Compatível com toque no celular (touch screen) e arraste no mouse.
- 💬 **Simulador de Cobrança WhatsApp**:
  - Converse diretamente com devedores inadimplentes em um chat interativo.
  - Escolha táticas de negociação (Amigável, Judicial ou Acordo à vista com desconto) para recuperar parcelas atrasadas.
- ⚖️ **Mini-Game de Leilão Judicial**:
  - Penhore carros, motos e imóveis de caloteiros.
  - Disputa de lances em tempo real com compradores virtuais e bata o martelo para arrematar pelo maior valor.
- 📈 **Gráfico Sparkline de Valuation em Tempo Real**:
  - Acompanhe a curva de crescimento do seu patrimônio líquido em tempo real gerada via Canvas.
- 🏛️ **Tesouro Selic 100% CDI**:
  - Aplique o caixa ocioso do banco com rendimento diário automático sem nenhum risco de inadimplência.
- 👔 **Conselho de Diretores Executivos (C-Level)**:
  - Contrate a CFO *Dra. Helena Rothschild*, o Head de Compliance *Dr. Fausto*, o Chefe de Cobrança *Brutus* e o CMO *Enzo Viral* para receber bônus passivos massivos.
- 🎵 **Música Lo-Fi Synth Nativa & SFX 2.0**:
  - Trilha sonora relaxante Lo-Fi sintetizada diretamente no navegador via **Web Audio API** (sem arquivos pesados para baixar).
  - Som de martelo de leilão, caixa registradora (*cha-ching*), arrasto de cartas e fanfarras.
- 🎊 **Efeito de Confetes Físicos**:
  - Chuva de confetes comemorativos ao bater metas, aprovar grandes empréstimos e alcançar o marco histórico de R$ 1 Bilhão!
- 🎨 **Personalização de Temas Visuais**:
  - Alterne entre os temas **Verde Esmeralda**, **Roxo Nubank Neon**, **Ouro Faria Lima** e **Cyberpunk Cyan**.
- 📱 **Pronto para Instalação como App Nativo (PWA)**:

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5 Semântico, CSS3 Moderno (Glassmorphism, Flexbox, CSS Grid, Custom Properties).
- **Engine Financeira:** Vanilla JavaScript Puro (Zero dependências externas, alta performance a 60 FPS).
- **Áudio:** Web Audio API (Sintetizador polifônico de efeitos sonoros e gerador de beats Lo-Fi procedural).
- **Gráficos & Efeitos:** Canvas API 2D nativo (Gráfico de linha de valuation e motor de partículas de confete).
- **Hospedagem:** GitHub Pages & GitHub Actions.
